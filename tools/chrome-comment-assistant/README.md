# 评论角度助手（Chrome）

根据当前贴文上下文，按**角色/评论角度**调用大模型生成多条候选评论，从中选一条**复制**或**填入评论框**。

## 支持平台

| 平台 | 说明 |
|------|------|
| **X / Twitter** | 读主推文、回复框填入 |
| **币安 Square** | binance.com/square 帖子与评论 |
| **OKX 社区** | okx.com 社区/帖子页 |
| **Bitget 社区** | bitget.com 社区/洞察页 |
| **Reddit** | 帖子页标题+正文，英文/中文跟帖 |
| YouTube / B 站 | 仍保留原有适配 |

打开扩展后会自动识别当前站点，并切换**平台专用评论角度**与字数建议。

## 安装

1. Chrome → `chrome://extensions` → 开启开发者模式  
2. 「加载已解压的扩展程序」→ 选择本目录：`tools/chrome-comment-assistant`  
3. 若已安装旧版，点扩展卡片 **重新加载**

## 配置

打开扩展 → **设置**：

| 项 | 说明 |
|----|------|
| API Key | **Ollama 可留空**；通义/DeepSeek 等云端必填 |
| API Base | 默认 Ollama：`http://127.0.0.1:11434/v1` |
| 模型 | 与 `ollama list` 一致，默认 `gemma-uncensored`（可按本机改） |
| 条数 | 每次生成 2～8 条 |

**Ollama 前置**：终端运行 `ollama serve`，并 `ollama pull <模型名>`。

也支持通义等 OpenAI 兼容网关（Base 改成对应 `/v1`，填 API Key）。

## 使用

1. 打开目标帖子页（可先选中一段正文）  
2. 点扩展图标 → 自动读取上下文并显示**平台徽章**  
3. 选「平台专用」或「通用」角色预设，可改自定义说明  
4. **生成评论** → 点选一条 → **复制所选** / **填入评论框**

### 平台专用角度示例

- **X**：短句互动、加密圈讨论  
- **币安**：广场互动、风险提示  
- **OKX**：专业跟评  
- **Bitget**：交易员视角  
- **Reddit**：自然跟帖、补充信息（英文为主）

## 技术说明

- `platforms.js`：平台检测、角色预设、评论框选择器  
- `content.js`：各站正文提取 + 填入评论框  
- `popup.js`：按平台组 prompt、调 OpenAI 兼容 API  
- Key 存在本机 `chrome.storage.local`

## 注意

- **不会自动点「发送」**，需人工确认后再发。  
- 交易所/社区评论请自行合规，避免喊单与投资建议。  
- 部分站点评论框在 Shadow DOM 或懒加载里，填入失败时会自动复制到剪贴板。
