## 卡片标注建议（当前缺口）

- 帖子层已有粗粒度 `source`（如 `bapi_profile` / `profile_cdp` / `x_api`）。
- 卡片层 `source_mode` 仍是业务模式（`list_realtime` / `binance_square`），**未**区分 `cookie+api` vs `cdp`。
- 应在卡片增加 `fetch_source`（或把 `source_modes` 附带 `cookie+api`/`cdp`），控制台展示「来源」。
